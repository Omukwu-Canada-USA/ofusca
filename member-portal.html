Do not expose secrets

Public key vs private key

The Supabase anon public key can be used in browser apps with Row Level Security. The Supabase service role key must never be placed in public website files, GitHub, Netlify environment exposed to frontend, or JavaScript.

  • Enable Row Level Security on all member tables.
  • Give members access only to their own profile.
  • Give executives/admins role-based access.
  • Store payment confirmation only, not card details.
  • Use Stripe/PayPal/Zelle/Interac for payments, not raw card collection.
