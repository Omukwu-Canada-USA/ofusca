Security, Privacy & Anti-Cloning Protection

OFUSCA protects its website, member records, photos, forms, and official materials through secure hosting, restricted access, consent-based publishing, and copyright protection.

Protection Shield

How this website is protected

  • Security headers reduce clickjacking, content injection, and browser abuse.
  • Only approved scripts, styles, images, and forms are allowed by the Content Security Policy.
  • Member profile forms include spam-reduction and consent controls.
  • Payment collection should be handled only by approved external payment processors.
  • OFUSCA materials are marked all-rights-reserved to discourage unauthorized cloning or reuse.
Important

No public site is impossible to clone.

Because browsers must download HTML, CSS, images, and JavaScript to display a public website, no public website can be made impossible to copy. OFUSCA reduces risk by keeping the source repository private, enforcing hosting security headers, using official domains, monitoring impersonation, and using takedown procedures when necessary.

Officer checklist

Required administrative protections

🔐

Use private repositories

Do not publish the website source code in a public GitHub repository. Keep it private and restrict access to approved officers or developers.

✅

Enable two-factor authentication

Protect Google, Netlify, GitHub, domain registrar, email, and payment accounts with two-factor authentication.

🛡️

Protect member data

Do not publish full dates of birth, children’s details, phone numbers, or addresses. Publish only what the member has approved.

💳

Use payment links safely

Never collect card numbers directly on this static site. Use official PayPal, Stripe, Zelle, Interac, or bank payment instructions.

📣

Review before publishing

All member spotlight posts, photos, and professional announcements should be reviewed before posting.

🚨

Report fake sites

If a fake OFUSCA site appears, capture evidence and report it to the domain registrar, host, search engines, and social platforms.

Human verification

Anti-robot protection for OFUSCA forms

The registration, payment confirmation, and contact forms now include a human verification layer using Netlify reCAPTCHA, honeypot spam traps, a required human confirmation checkbox, and timing checks that discourage automated bot submissions.

  • CAPTCHA challenge on live Netlify forms
  • Hidden bot-field trap for spam scripts
  • Browser-generated submission check
  • Short-delay protection against instant bot submissions
  • Admin review before member information is publicized

Note: CAPTCHA reduces robot activity, but it should be combined with private repository settings, two-factor authentication, approved payment links, and careful administrator review.
