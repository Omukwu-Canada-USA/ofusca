Member Database & Integration Setup

This page prepares OFUSCA for Google Sheets member records now and Supabase authentication/member portal later, without exposing private database keys on the public website.

Member RegistrationPortal Plan
Recommended architecture

Start simple, then grow into a secure portal.

For the immediate phase, use Google Forms/Sheets for member records. For the next phase, use Supabase Auth and a protected database for login, dues history, profile updates and member-only pages.

1

Public Website Form

Members register, update profiles, submit birthdays, profession, marital status, children, photos, publicity consent and volunteer interests.

2

Google Sheet Database

The secretary, PRO and financial team can filter birthdays, dues, donations, member spotlight items and approved business profiles.

3

Supabase Auth Later

Members create secure accounts, log in, update records, upload documents, check dues status and receive member-only announcements.

Option B — website form to Google Sheet

Apps Script endpoint option

This option keeps the website design and sends form submissions into a Google Sheet through a Google Apps Script Web App endpoint.

  1. Create the Google Sheet tabs listed below.
  2. Open Extensions → Apps Script.
  3. Paste the script from assets/docs/google-apps-script-member-database.js.
  4. Deploy as Web App with access set to “Anyone” only for form submissions.
  5. Paste the Web App URL into assets/js/integrations-config.js.

Security warning: do not put private passwords, Supabase service role keys, bank credentials, or payment secrets in public JavaScript.
